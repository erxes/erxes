# erxes-ui catalog

Generated by `tools/ui-exports.ts` from the doc comments in erxes-ui. Find what you need here
before writing a component, hook or helper, and import it from `erxes-ui`.

## Pages

Copy the screen beside each kind. `ui/…` is your plugin's own template; `apps/web/…` is
core's, in the erxes repo on branch `postgre`. The `ui-patterns` skill has the rules.

| Page                     | Build with                                                          | Copy                                                            |
| ------------------------ | ------------------------------------------------------------------- | --------------------------------------------------------------- |
| List                     | `PageHeader`, `ViewBar`, `ListFilter`, `RecordTable`                | `ui/src/modules/items/ItemsPage.tsx`                            |
| Grouped list (by status) | `RecordList`, `DisplayMenu`, `useListDisplay`                       | none in core yet                                                |
| Board                    | `DisplayMenu`, `useListDisplay`                                     | `apps/web/src/modules/leads/LeadsBoard.tsx`                     |
| Record detail            | `PanelSection`, `PanelField`, `RecordTableInlineCell`, `RecordPage` | `ui/src/modules/items/ItemPanel.tsx`                            |
| Create/edit form         | `PanelFormLayout`, `PanelFormRow`                                   | `ui/src/modules/items/ItemPanel.tsx`                            |
| Settings list            | `PageHeader`, `RecordTable`                                         | `apps/web/src/modules/settings/tags/TagsSettingsPage.tsx`       |
| Settings form            | `Form`, `Switch`, `ScrollArea`                                      | `apps/web/src/modules/settings/profile/ProfileSettingsPage.tsx` |

## Page

- `<AppLayout id sidebar footer title>` An app's full-height layout under core's top bar, with its own sidebar.
- `<AppLayoutFooterLink to name icon>` A link pinned to the foot of an app sidebar, in `AppLayout`'s `footer`.
- `<NavigationMenuLinkItem name icon to isActive label>` A sidebar link that lights up while the address is under its `to`.
- `<PageContainer>` A page's outer box, full height, with `PageHeader` first inside it.
- `PageHeader.{Start, End}` A page's title bar, with the breadcrumb and its one primary action.
- `<PageSubHeader variant>` A bar under the page header with a rule below it, for tabs or controls.

## Lists

- `<DisplayMenu list displays>` The Display menu in a list's filter bar: table, board or grouped list.
- `EnumCursorDirection` Which way a cursor-paged table loads more rows: forward or backward.
- `Filter.{Trigger, Popover, Item, CommandItem, View, …}` Parts of a filter popover and bar, for a page without saved views.
- `<ListFilter recordType>` A list's filter: a view bar button, and a chip row while it filters.
- `<ListFilterEmpty records fallback>` A list's empty state while `ListFilter` filters it, with Clear filters.
- `listFilterQuery` The URL params holding a list's filter, as nuqs parsers.
- `<ListViewsProvider views>` Gives every list with a `recordType` saved views, as core's lists have.
- `RecordList.{Provider, Skeleton, useSelection}` Rows grouped under headers that fold away, such as tasks by status.
- `type RecordListGroup { id, label, icon, rows, action }` A run of rows under one header, such as the tasks in one status.
- `RecordTable.{Provider, Header, Head, InlineHead, RowList, …}` The table every record list uses; never `Table` or a plain `<table>`.
- `type RecordTableColumnDef` A record table column for rows of `TData`.
- `RecordTableInlineCell.{LabelledBy, Trigger, Content, Anchor}` A table cell value, and the trigger and popover that edit it in place.
- `type TListDisplay` How a list shows its records: grouped rows, a table or a board.
- `type TListFilterField { path, label, type, options, icon, … }` A field a list can filter by, for `ListFilter`'s `fields`.
- `type TListFilterProps` The props of `ListFilter`: its `id`, `fields`, lookups and record count.
- `type TListViews { Tabs, Changes }` The host's saved views for a list.
- `type TPluginListType` A plugin's list: its record type, `<plugin>:<record>` (`sales:deal`).
- `type TRecordTableSort { by, direction }` The order a list's rows come in: by a column, either way.
- `type TViewTabsProps { recordType, allLabel }` The props of the host's saved-view tabs: the list and its "All …" label.
- `useFilterContext()` Controls of the enclosing `Filter`: open or close it and switch views.
- `useListDisplay(list, displays)` The display a list shows, as picked in its Display menu.
- `useListFilterParams()` `ListFilter`'s conditions and search, as params for the list's query.
- `useListViews()` The host's saved views, for `ViewBar` and `ListFilter`.
- `<ViewBar allLabel recordType tabs>` A list's one bar under its page header: views left, filter right.

## Records

- `type CompanyContact { id, primaryName, primaryEmail, primaryPhone, avatarUrl }` What a company reads as: core's `Company` has these fields and more.
- `companyTitle(company)` A company's name, else its email or phone.
- `<ContactLink contentType contentId contacts placeholder>` A customer or company as a chip: its avatar and name.
- `type ContactQueries { customer, company }` Where customers and companies come from, as TanStack query options.
- `type ContactSearch { search, ids }` What a contact search asks for: matches, or the contacts with these ids.
- `type ContactSearchQueries { customers, companies }` Where a filter's `customer` and `company` fields search contacts.
- `type CustomerContact { id, firstName, middleName, lastName, primaryEmail, … }` What a customer reads as: core's `Customer` has these fields and more.
- `customerTitle(customer)` A customer's name, else its email or phone.
- `<PanelDescriptionEditor value scope readonly isHTML onSave>` A record's description as a full-size tab.
- `<PanelDescriptionField label value scope readonly isHTML>` A rich-text description row in the side panel, across its width.
- `PanelExpansionContext` Provided by the host's record panel; erxes-ui's panel parts read it.
- `<PanelField label icon placeholder htmlFor cell>` A side panel row: icon and label, then the value as a table cell.
- `<PanelFieldTrigger>` A table cell trigger with the side panel's rounded hover.
- `<PanelFormLayout onCancel saving saveLabel>` A new record's form in the side panel: its rows, then Cancel and Save.
- `<PanelFormRow label icon required error hint>` One field of a form in the side panel, laid out like `PanelField`.
- `<PanelLabel tooltip>` A side panel label cut at two lines, with the full text on hover.
- `<PanelSection title icon nested>` A plain heading that groups the side panel's rows.
- `<RecordOpenerProvider open openNew current dismiss>` The host app's way to open records, which `useOpenRecord` calls.
- `RecordPage` A record on its own page, as core draws a customer's.
- `type RecordPanelControls { record, tab, setTab, close, dismiss, … }` What a record shown in core's panel, or on its own page, can do to it.
- `RecordPanelProvider` Web gives each record it shows its controls.
- `type RecordRef { contentType, contentId }` A record the host can open, by `contentType` and `contentId`.
- `RecordTimeline` Core's timeline of notes, calls and events for a plugin's record.
- `type RecordTimelineProps { type, id }` Which record `RecordTimeline` shows: its timeline type and id.
- `setRecordPage` Web registers how a record draws on its own page.
- `setRecordTimeline` Registers core's timeline; web calls it at startup and plugins don't.
- `type TContactContentType` The customer or company types `ContactLink` shows.
- `useOpenRecord()` Opens a record, or a new draft, in core's side panel.
- `usePanelExpanded()` Whether the record shows at full size on its own page.
- `useRecordPanel()` The record a slot is in, and what the slot can do to it.

## Fields and pickers

- `<ConditionsEditor>` Edits a condition group of rules, for automations and advanced filters.
- `<Editor>` The block editor, fetched the first time one renders.
- `editorText(content)` Stored editor content, block JSON or HTML, as the plain text it shows.
- `<EmailDisplay maxVisible primaryEmail emails emailValidationStatus>` A record's emails as chips, the primary one with its validation mark.
- `<EmailListField recordId onValueChange onValidationStatusChange noValidation primaryEmail>` An editable list of a record's emails, each with its own menu.
- `<EntityPicker items itemKey renderItem value onValueChange>` The searchable list behind every record picker; build a picker on it.
- `<FullNameField firstName lastName onValueChange scope>` First and last name inputs in a popover, saved when it closes.
- `<FullNameValue>` The name `FullNameField` is editing, or "Unknown" when it is empty.
- `<IconComponent name>` A Tabler icon by its name, such as one stored on a record.
- `<IconPicker value onValueChange>` A button that picks a Tabler icon from a searchable list in a popover.
- `<IconsProvider>` Loads the Tabler icon set in the background for `IconComponent`.
- `isRule(rule)` Whether a condition entry is a rule rather than a nested group.
- `<LookupPicker lookup value onValueChange multiple placeholder>` A button that picks members or tags, one or several with `multiple`.
- `type Member { id, email, fullName, username, avatarUrl, … }` A team member as the pickers show one.
- `<MemberInline memberId members placeholder size>` A member's avatar and name by id, or a placeholder without one.
- `memberName(member)` How a member reads: the display name, else the username, else the email.
- `type MemberQueries { team, byIds }` Where members come from, as TanStack query options.
- `<NumberField placeholder value scope onSave onValueChange>` A number in a table cell or panel row that edits in a popover.
- `<PhoneDisplay maxVisible primaryPhone phones phoneValidationStatus>` A record's phones as chips, the primary one with its validation mark.
- `<PhoneField recordId onValueChange onValidationStatusChange primaryPhone phones>` An editable list of a record's phones, each with its own menu.
- `<PhoneInput value onChange defaultCountry placeholder onEnter>` A phone input with a country flag picker that formats as you type.
- `RelativeDateDisplay.{Value}` A date as how long ago it was, with the date and time on hover.
- `SelectMember` The member picker as a table cell and as a field.
- `<SexDisplay value>` A sex code as its label, or nothing when it is not known.
- `<SexField value onValueChange>` A searchable list to pick a sex code, for a popover or cell editor.
- `type Tag { id, name }` A tag as the pickers show one: core's `Tag` has these fields and more.
- `type TagsQuery` TanStack query options for the tags of one record type.
- `type TConditionField { path, label, type, options, group, … }` A field conditions can use: a record's, or an earlier step's output.
- `type TConditionGroup { match, rules }` Rules (or nested groups) that must all, or any, hold.
- `type TConditionLookups { members, tags, contacts }` Where `member`, `tags`, `customer` and `company` values pick from.
- `type TConditionRule { path, op, value }` One rule of a condition: a `path`, an operator and maybe a value.
- `<TextField placeholder value scope onSave onValueChange>` A text value in a table cell or panel row that edits in a popover.
- `useMemberOptions(members, enabled, picked)` The active team members as picker options.
- `useMembersById(ids, members)` Members by id, any status.
- `useTagOptions(tags, enabled)` A record type's tags as picker options; none without `tags`.

## Components

- `Accordion.{Item, Trigger, Panel}` Stacked sections whose headers fold their content open and shut.
- `Alert.{Title, Description}` An inline notice: icon, title and text, plain, warning or destructive.
- `AlertDialog.{Action, Cancel, Content, Description, Footer, …}` A modal that asks the member to confirm or cancel one action.
- `Avatar.{Image, Fallback}` A person's picture, round or square, falling back to their initials.
- `type AvatarProps` Base UI avatar props plus `corners`, `ring` and `size`.
- `<BackgroundGradientAnimation containerClassName>` Slowly moving colour blobs behind `children`, as a backdrop.
- `<Badge variant size onClose>` A small tinted label for a status, tag or count; `onClose` adds an x.
- `type BadgeProps { onClose }` Div props plus `variant`, `size` and `onClose`, which adds a remove x.
- `badgeVariants` The badge's classes by `variant` and `size`, to style another element.
- `Breadcrumb.{List, Item, Link, Page, Separator, …}` The trail of links to the current page, on the left of a `PageHeader`.
- `<Button variant tone size>` A button in the theme's variants, tones and sizes; native by default.
- `type ButtonProps` Base UI button props plus `variant`, `tone` and `size`.
- `buttonVariants(props)` Button classes by `variant`, `tone` and `size`, to style a link as one.
- `<Calendar classNames>` A month grid to pick a day or range, with month and year selects.
- `type CalendarProps` react-day-picker's `DayPicker` props.
- `Card.{Header, Footer, Title, Description, Content}` A raised panel with header, title, description, content and footer.
- `type ChartConfig` Each series' label, icon and colour by data key, for `ChartContainer`.
- `<ChartContainer config style>` The frame for a recharts chart: size, theme and series colours.
- `<ChartLegendContent hideIcon payload verticalAlign nameKey>` The themed body for a recharts `Legend`: each series' icon and label.
- `<ChartTooltipContent>` The themed body for a recharts `Tooltip`, labelled from the config.
- `<Checkbox>` A themed checkbox; pass `indeterminate` for a partial selection.
- `ChoiceboxGroup.{Item}` Radio choices drawn as large tiles with a title and text.
- `Collapsible.{Trigger, TriggerIcon, Panel}` One section that folds open and shut, with a caret icon for its trigger.
- `ColorPicker.{Provider, Trigger, Content}` A swatch button that opens preset colours and a hex input in a popover.
- `Combobox` Parts of a popover picker: trigger, value, content, check, load-more.
- `Command.{Dialog, Input, List, Empty, Group, …}` A searchable list of items to pick or run, built on cmdk.
- `CommandBar.{Value, Bar}` A bar floating at the page bottom with bulk actions for a selection.
- `ContextMenu.{Trigger, Content, Item, Group, Label, …}` A menu that opens on right-click, beside the pointer.
- `<CopyText value>` Text that copies `value` to the clipboard on click and shows "Copied!".
- `<DateInput>` A calendar date typed in.
- `<DatePicker {...DatePickerProps}>` A date field with a calendar popover, for one day, several or a range.
- `Dialog.{Trigger, Close, Portal, Backdrop, Content, …}` A centered modal over a dimmed page, such as an image lightbox.
- `<DragHandle variant>` A small grip button to drag a row or card by, for a sortable list.
- `DropdownMenu.{Trigger, Group, Sub, SubTrigger, SubContent, …}` A menu of actions that opens from a button, such as a row's "more" menu.
- `Empty.{Header, Title, Description, Content, Media}` A list's or page's empty state: icon, title, a line and an action.
- `Form.{Control, Description, Field, Item, Label, …}` react-hook-form's provider with field, label, control and error parts.
- `HoverCard.{Trigger, Content}` A preview card that opens when the pointer rests on a link, after 700ms.
- `<IconTip label hotkey>` The hover label of an icon-only button, with its shortcut if it has one.
- `InfoCard.{Content}` A tinted dashboard tile: a caps title, an info tip and a content box.
- `Input.{Number}` A themed text input; `Input.Number` adds thousands separators.
- `InputGroup.{Addon, Input, Textarea}` An input or textarea with an icon or button inside the same box.
- `<Kbd variant>` A keyboard key, such as a shortcut in a tooltip or menu.
- `<Label variant htmlFor>` A form control's label, a native `<label>` since Base UI has none.
- `<MultipleSelector>` Picks several options from a list, shown as removable badges.
- `type MultiSelectOption { value, label }` One option of `MultipleSelector`: its value and the label shown.
- `Popover.{Trigger, Content, Close}` A floating box anchored to its trigger, for a picker or a few controls.
- `RadioGroup.{Item}` A set of radio buttons where one value is picked.
- `Resizable` Side-by-side panels with handles that drag their sizes.
- `ScrollArea.{Root, Viewport, Bar}` A scrolling box with thin scrollbars that show on hover or scroll.
- `Select.{Group, Value, Trigger, Content, Label, …}` A dropdown to pick one value from a short fixed list.
- `Separator.{Inline}` A thin horizontal or vertical line between sections.
- `Sheet.{Trigger, View, Backdrop, Content, Header, …}` A panel that slides in from a page edge over a dimmed page.
- `Sidebar.{Content, Footer, Group, GroupAction, GroupContent, …}` A collapsible side navigation with groups, menus and sub-menus.
- `<Skeleton radius>` A pulsing grey block that holds the place of content while it loads.
- `<Slider>` A draggable slider for one number or a range.
- `<Spinner size show area containerClassName>` A spinning loader; `area` pads it to stand in for a section or page.
- `<StringArrayInput value onValueChange placeholder>` A list of short strings as removable badges.
- `<Switch size>` An on/off toggle for a setting that applies as soon as it flips.
- `<TabButton render variant active dragging split>` A tab-looking button for a strip that isn't a `Tabs` list.
- `Table.{Header, Body, Footer, Head, Row, …}` A plain styled HTML table, for small static grids of values.
- `Tabs.{List, Trigger, Content}` Tabs that switch between panels of one view.
- `<Textarea variant text truncate>` A themed multi-line text box; `flat` and `ghost` drop the border.
- `TextOverflowTooltip.{Input}` Text cut with an ellipsis that shows the full value in a tooltip.
- `<TimeField>` A time of day.
- `<Toaster>` Draws the toasts `toast()` raises; core's web app already mounts it.
- `<Toggle variant size>` A button that stays pressed or not, such as bold in a toolbar.
- `ToggleGroup.{Item}` A row of toggle buttons where one or several stay pressed.
- `Tooltip.{Provider, Trigger, Content}` A short label that shows on hover or focus of its trigger.
- `Upload` An image upload: a preview tile, an upload button and a remove button.
- `useFieldControl()` A form row's label, error and state for its control.

## Plugin runtime

- `addPluginStyles(plugin, css)` Adds a plugin UI's compiled Tailwind to the page, minus what web has.
- `DASHBOARD_WIDGET_PREVIEWS` Every schematic the widget catalog can draw for a dashboard widget.
- `type FileStorageAdapter { upload, remove }` Where erxes-ui's upload hooks and components send files.
- `getPluginAssetsUrl(pluginName, url)` A file's URL in a plugin UI's deployed `assets` folder.
- `getPluginRuntime()` The host's plugin runtime, or null outside erxes.
- `type IUIConfig { name, path, icon, settings, recordSections, … }` A plugin UI's `CONFIG`, exported from its `./config` remote.
- `pluginFetch(plugin, path, init)` `fetch` against a plugin's API as the signed-in member.
- `pluginJson(plugin, path, schema, init)` JSON in, JSON out, checked against `schema`.
- `type PluginLiveMessage` A message on core's live stream: a plugin's changed topics, or resync.
- `type PluginRuntime { session, subscribe }` What the host gives plugin UIs: plugin API sessions and the live stream.
- `type PluginSession { token, expiresAt, apiUrl }` A member's short-lived token for one plugin's API, and its address.
- `setFileStorage(next)` Sets where uploads go; web calls it at startup and plugins don't.
- `setPluginRuntime(next)` Sets the plugin runtime; web calls it at startup and plugins don't.
- `type TDashboardWidget { name, title, description, icon, preview, … }` A plugin's tile for core's home dashboard.
- `type TDashboardWidgetPreview` The schematic a dashboard widget shows in the widget catalog.
- `type TPanelRecordType { contentType, title, icon, detailPath, Title, … }` A record type a plugin shows in core's side panel.
- `type TPluginSettingsPage { path, label, icon }` A plugin's settings page, linked from core's settings sidebar.
- `type TPropertyValue` A custom field's value: text, number, date, yes/no or options.
- `type TRecordContacts { customerIds, companyIds }` The customers and companies a record is about.
- `type TRecordDraftProps { defaults, onCreated, onCancel }` Props of a plugin record type's `New` slot, the draft form.
- `type TRecordProperties { type, values, save }` Custom fields on a plugin record type, whose values the plugin keeps.
- `type TRecordSection { contentType, title, icon, component }` A plugin's section on a customer's or company's detail in core's panel.
- `type TRecordSectionProps { contentType, contentId }` What a record section is given: the customer or company it shows on.
- `type TRecordSlotProps` What each slot of a plugin record is given: the record.
- `type TRecordTab { value, label, icon, after, component }` A plugin record type's own tab, after core's Detail or Activity tab.
- `type TRelationTab { name, title, icon, hosts, component }` A plugin's tab on other records' panels, listing its own records.
- `type TRelationTabProps` Props of a relation tab: the record it shows on, and its contacts.
- `useLiveSignal(plugin, topics, onSignal)` Runs `onSignal` when a plugin says one of `topics` changed, to refetch.

## Hooks and helpers

- `amountStep(currency)` A number input's `step` for a currency: 0.01 for USD, 1 for JPY.
- `cn` Joins classes and drops the ones a later class overrides.
- `formatMoney(amount, currency, language)` An amount as people read it in `language`: 150000 MNT → "MNT 1,500.00".
- `formatPhoneNumber({ defaultCountry, value })` A phone number formatted as people write it, even half typed.
- `formatter(language)` The formatters for `language` (an i18next code), for code outside React.
- `fromAmountInput(text, currency)` A number input's text as an amount in minor units: "12.5" USD → 1250.
- `isUndefinedOrNull(value)` True for `null` and `undefined`, and narrows the value's type.
- `jsonOf(schema)` A zod schema for a JSON string that decodes to `schema`.
- `LANGUAGES` The UI's languages, each with its own name and date-fns locale.
- `localTimeZone()` The browser's time zone ("Asia/Ulaanbaatar"), when it says.
- `oneOf(options, value)` `value` narrowed to one of `options`, else undefined.
- `<PopoverScoped scope onOpenChange onEnter closeOnEnter dependencies>` A `Popover` that takes over the hotkey scope while it is open.
- `readImage(value)` The address to show a stored file at.
- `SexCode` A person's sex as an ISO/IEC 5218 code.
- `stored({ key, schema, initial, session })` An atom kept in browser storage under `key`.
- `storedFamily({ key })` One stored atom per id (a table, a user, a list), under `<key>:<id>`.
- `textOf(value)` A stored value of any JSON shape as text, for showing or editing it.
- `ThemeOption` The UI theme a member picks: `light`, `dark` or `system`.
- `themeState` The member's theme choice as a jotai atom, kept in localStorage.
- `toAmountInput(amount, currency)` An amount as a number input's value, with all the currency's decimals.
- `toast({ title, description, variant, action })` Shows a toast: `toast({ title, description, variant: 'success' })`.
- `toIsoDay(date)` A local day as stored and typed, `yyyy-MM-dd`, in every language.
- `useConfirm()` `confirm` shows a confirmation dialog in its own root.
- `useFocusFirstField(ref)` Puts the cursor in the first field under `ref` when the form opens.
- `useFormat()` Date, number and money formatters in the UI's language, for components.
- `useItemKeys(length)` Stable React keys for an editable list whose items have no id.
- `useMoney()` `formatMoney` in the UI's language.
- `usePageHotkey(keys, action, { when, useKey })` A page shortcut, skipped while typing or while a dialog or menu is open.
- `usePreviousHotkeyScope()` Sets a hotkey scope and remembers the old one to go back to.
- `useScopedHotkeys(keys, callback, scope, dependencies, options)` Runs `callback` on `keys` while the hotkey `scope` is enabled.
- `useToast()` `{ toast }` as a hook; calling `toast` directly does the same.
- `useUpload()` Uploads files to the host's file storage, one request per file.
- `zoneOffset(zone)` A time zone's offset today, like "UTC+8".
