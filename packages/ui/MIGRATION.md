# erxes-ui: erxes 3.x to Base UI

| erxes 3.x                                                                                                                                                                                                              | New core                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `asChild` on any part (`Button`, triggers, `Close`, `Sidebar.MenuButton`, `Sidebar.MenuSubButton`, `RelativeDateDisplay`)                                                                                              | `render={<Element … />}`; the old child's children become the part's children                                                         |
| `<Button asChild><Link …/></Button>`                                                                                                                                                                                   | `<Link className={buttonVariants({ variant, size })} …/>`                                                                             |
| `data-[state=open]:`                                                                                                                                                                                                   | `data-popup-open:` on a trigger, `data-open:` on a popup                                                                              |
| `data-[state=closed]:`                                                                                                                                                                                                 | `data-closed:`                                                                                                                        |
| `data-[state=checked]:` / `data-[state=unchecked]:`                                                                                                                                                                    | `data-checked:` / `data-unchecked:`                                                                                                   |
| `data-[state=active]:` (tabs)                                                                                                                                                                                          | `data-active:`                                                                                                                        |
| `data-[state=on]:` (toggle)                                                                                                                                                                                            | `data-pressed:`                                                                                                                       |
| `data-[highlighted]:`, `data-[disabled]:`                                                                                                                                                                              | `data-highlighted:`, `data-disabled:`                                                                                                 |
| `--radix-popover-trigger-width`, `--radix-select-trigger-width` …                                                                                                                                                      | `--anchor-width`                                                                                                                      |
| `--radix-*-content-available-height`                                                                                                                                                                                   | `--available-height`                                                                                                                  |
| `--radix-accordion-content-height`                                                                                                                                                                                     | `--accordion-panel-height`                                                                                                            |
| `Tooltip delayDuration={n}`                                                                                                                                                                                            | `Tooltip.Trigger delay={n}`                                                                                                           |
| `Tooltip.Provider delayDuration` / `skipDelayDuration`                                                                                                                                                                 | `Tooltip.Provider delay` / `timeout`                                                                                                  |
| `HoverCard openDelay` / `closeDelay`                                                                                                                                                                                   | `HoverCard.Trigger delay` / `closeDelay`                                                                                              |
| `Popover.Anchor`                                                                                                                                                                                                       | `Popover.Content anchor={ref}`                                                                                                        |
| `Popover.Content` / `Combobox.Content` `onOpenAutoFocus`, `onCloseAutoFocus`                                                                                                                                           | `initialFocus`, `finalFocus` (`false` keeps focus where it is)                                                                        |
| `onEscapeKeyDown`, `onInteractOutside`, `onPointerDownOutside`                                                                                                                                                         | root `onOpenChange={(open, details) => …}`: `details.reason` is `'escape-key'` or `'outside-press'`, `details.cancel()` keeps it open |
| `PopoverScoped onOpenChange(open)`                                                                                                                                                                                     | `onOpenChange(open, details?)`                                                                                                        |
| `Dialog.Portal`                                                                                                                                                                                                        | drop it: `Dialog.Content` portals itself                                                                                              |
| `Dialog.Overlay`, `Sheet.Overlay`                                                                                                                                                                                      | drop it: `Dialog.Content` and `Sheet.View` render the backdrop                                                                        |
| `DialogProps`                                                                                                                                                                                                          | `React.ComponentProps<typeof Dialog>`                                                                                                 |
| `<Sheet.Close asChild><Button>…</Button></Sheet.Close>`                                                                                                                                                                | `Sheet.Close` takes no children (it is the header's x); another close button calls `onOpenChange(false)`                              |
| `AlertDialog.Content` focus                                                                                                                                                                                            | starts on `AlertDialog.Cancel`; pass `initialFocus={ref}` to change it                                                                |
| `DropdownMenu.Item onSelect` / `ContextMenu.Item onSelect`                                                                                                                                                             | `onClick`                                                                                                                             |
| `<DropdownMenu.Item asChild><a href></a></DropdownMenu.Item>`                                                                                                                                                          | `<DropdownMenu.LinkItem href>`; router links: `LinkItem render={<Link to />}`                                                         |
| `DropdownMenu.Portal`                                                                                                                                                                                                  | drop it: `DropdownMenu.Content` portals itself                                                                                        |
| `ContextMenu.Portal`, `Sub`, `SubTrigger`, `SubContent`, `RadioGroup`, `RadioItem`, `CheckboxItem`                                                                                                                     | gone; use a `DropdownMenu` for nested or checkable items                                                                              |
| `Select.Primitive.*`                                                                                                                                                                                                   | `Select.Trigger`, `Select.Item` …; `Select.Item` renders its own check and text                                                       |
| `Select.ScrollUpButton`, `Select.ScrollDownButton`                                                                                                                                                                     | drop them: `Select.Content` renders both                                                                                              |
| `Select value=""`                                                                                                                                                                                                      | still means nothing selected; `onValueChange` never reports a clear                                                                   |
| `Tabs.Primitive`                                                                                                                                                                                                       | gone                                                                                                                                  |
| `Tabs.Content`                                                                                                                                                                                                         | same name, renders a Base UI `Tabs.Panel` (`keepMounted` to keep it in the DOM)                                                       |
| `Accordion.Content`, `Collapsible.Content`                                                                                                                                                                             | `Accordion.Panel`, `Collapsible.Panel`                                                                                                |
| `Accordion type="single" collapsible` / `type="multiple"`                                                                                                                                                              | default / `multiple`; `value` is always an array                                                                                      |
| `Collapsible.TriggerButton`                                                                                                                                                                                            | `Collapsible.Trigger render={<Button … />}`                                                                                           |
| `ToggleGroup type="single" value="a" onValueChange={(v) => …}`                                                                                                                                                         | `ToggleGroup value={['a']} onValueChange={([v]) => …}`; `multiple` for several                                                        |
| `Checkbox checked="indeterminate"`                                                                                                                                                                                     | `Checkbox checked={false} indeterminate`                                                                                              |
| `Checkbox onCheckedChange={(c) => c === true}`                                                                                                                                                                         | `onCheckedChange={(checked) => …}` gets a boolean                                                                                     |
| `Slider value={[n]} onValueChange={([n]) => …}`                                                                                                                                                                        | the same, or `value={n} onValueChange={(n) => …}`; `onValueCommit` → `onValueCommitted`                                               |
| `<TimeField value={Time} onChange hourCycle><DateInput /></TimeField>`                                                                                                                                                 | `<TimeField value="HH:mm" onValueChange={(time) => …} />`; no child, the browser picks 12 or 24 hours                                 |
| `TimeField isDisabled`                                                                                                                                                                                                 | `disabled`                                                                                                                            |
| `DateInput` (a date)                                                                                                                                                                                                   | `<DateInput value="yyyy-MM-dd" onValueChange={(date) => …} />`                                                                        |
| `TextOverflowTooltip delayDuration`                                                                                                                                                                                    | gone (100 ms)                                                                                                                         |
| `TextOverflowTooltip.Input onChange={(value) => …}`                                                                                                                                                                    | `onValueChange={(value) => …}`                                                                                                        |
| `Command.Dialog dialogContentClassName`                                                                                                                                                                                | `className`; `title` is required (read by screen readers, not shown)                                                                  |
| `MultipleSelector defaultOptions`                                                                                                                                                                                      | `options`                                                                                                                             |
| `MultipleSelector inputProps={{ id }}`                                                                                                                                                                                 | `id`                                                                                                                                  |
| `MultipleSelector onSearch`, `onSearchSync`, `delay`, `triggerSearchOnFocus`, `loadingIndicator`, `groupBy`, `maxSelected`, `onMaxSelected`, `selectFirstItem`, `badgeClassName`, `commandProps`, `hideClearAllButton` | gone; it filters `options` itself                                                                                                     |
| `toast({ title, description, variant })`                                                                                                                                                                               | the same; returns `{ id, dismiss }`                                                                                                   |
| `useToast().dismiss(id)`, `toast().update`                                                                                                                                                                             | the `dismiss` returned by `toast()`; no update                                                                                        |
| `composeRefs` from `radix-ui/internal`                                                                                                                                                                                 | `radix-ui` is not available; merge refs with a callback ref                                                                           |
| a toast found by `getByRole('status')` in tests                                                                                                                                                                        | `getByRole('dialog', { name })`                                                                                                       |
