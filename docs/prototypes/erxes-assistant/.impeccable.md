## Design Context

### Users
Sales, support, and operations teammates working anywhere in erxes. They want help with what is on screen without losing their place.

### Brand Personality
Precise, composed, helpful. Page-aware rather than chatty: the Assistant shows where its answers come from, and acts.

### Aesthetic Direction
Keep erxes's existing heading font (Inter) and the existing Assistant logo. Neutral light surfaces, one indigo accent for sources and selection, near-black primary actions. Inspired by the Dia browser's page-aware chat. Default presentation is a floating Lens; users can pin it as a docked Companion. Avoid decorative gradients, new display fonts, mascots, crowded tab strips.

### Design Principles
1. Answer about the page you're on; the current page is shared by default and removable.
2. Show sources on the page itself (pins, highlights), not only in the chat.
3. Actions run directly from the answer; say what happened and offer Undo.
4. Lens by default, Companion on demand. Draft and conversation survive the switch.
5. Visible keyboard focus; pointer targets ≥24px, touch targets ≥44px.
