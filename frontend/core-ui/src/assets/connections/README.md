# Provider marks

- `sendgrid.svg`: SendGrid brand mark, sourced from https://www.vectorlogo.zone/logos/sendgrid/sendgrid-icon.svg.
- OpenAI, Cloudflare, Grok and Kimi reuse the existing local brand assets in the parent directory.
- Amazon services use the existing Tabler AWS brand icon. SMTP uses a mail icon because it is a protocol, not a brand.

Marks identify the service being configured; they do not imply endorsement. No remote logo requests are made while users enter account details.
